The Big-O Focus
The 2 strategies used in LoginSystem.cpp linked with the "Engineer_h.cpp" and "Engineer.cpp" files  are Sequential search and Binary search
A Sequential search does not requires sorted and the worst case is (O(n)) 
        it works on unsorted engineer list; simplest to implement

A binary search does require a sorted and the worst case is a O(log n)
        Needs sortByID()(O(n log n), one-time)run first
